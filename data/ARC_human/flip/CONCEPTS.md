# flip 폴더 — Concept 설계

`flip` 폴더의 concept은 그리드 안 객체를 **대칭(반전)** 시키는 변환을 다룬다. 파일 포맷/네이밍/색상 규칙은 루트 `HARNESS.md`를 따르고, 객체 분류·색상 구성·선택 근거 축은 `rotate/CONCEPTS.md`와 동일한 설계를 공유한다.

> **개정 (2026-07-25)**: 대각선 반전을 없애고(좌우·상하 2종만), 이동을 제거(전부 제자리 반전)하고, parity 축을 제거한 뒤 대상 객체 사이즈를 rotate와 동일한 고정 틀 10종에서 무작위로 뽑는 방식으로 바꿨다. 아래는 개정된 설계이며, 이전(4방향/이동/기준선/parity) 설계는 폐기했다.

## 0. 전제 — 객체 크기 (사이즈 틀)

대상 객체의 bbox 크기는 rotate와 동일한 **고정 틀 10종**에서 무작위로 고른다. 대각선 반전이 없으므로 정방형 제약은 필요 없다.

```
(1,3) (3,1) (2,2) (2,4) (4,2) (3,3) (3,5) (5,3) (4,4) (5,5)
```

## 1. 기본 분류 (객체 개수) — rotate와 동일

| 분류 | 설명 |
|---|---|
| **F-단일** | 그리드에 반전 대상 객체가 하나뿐 |
| **F-다** | 그리드에 여러 객체가 존재, 그중 하나만 반전 대상 |

### 1-1. F-단일: 객체 색상 구성 (3종)

1. **단색** — 객체를 이루는 모든 셀이 같은 색
2. **부분 다색** — 색상 종류가 1보다 많고 객체 크기(셀 수)보다는 적음
3. **전체 다색** — 색상 종류 수 = 객체 크기(셀 수). (셀 수 ≤ 9)

### 1-2. F-다: 객체 선택 근거 (3종)

1. **색상** — 대상 객체의 색을 파일 전체에서 하나로 고정(나머지 속성은 예시마다 랜덤).
2. **크기** — 대상 객체는 셀 수가 **파일 내 고정 상수 X**인 객체(색·모양처럼 특정 값을 골라냄). distractor는 X가 아닌 크기(더 클 수도 있음). "가장 큰 객체"가 아니다.
3. **모양** — 대상 도형(cell 패턴)을 파일 내에서 하나로 고정해 모든 예시에 재사용(색은 예시마다 랜덤). distractor는 다른 모양.

> F-다의 각 객체는 **단색(monochrome)**. **색상 중복 금지**: 한 grid 안 모든 객체의 색은 서로 달라야 한다.

## 2. ~~가로/세로 parity 축~~ — 폐기

이전 설계의 parity 축은 제거. §0의 고정 사이즈 틀로 대체하며, **사이즈는 조합 축이 아니라** 문제마다 무작위로 뽑는 자유 파라미터다.

## 3. flip 방향 — 좌우 / 상하 2종

대각선 반전은 폐기. 반전축은 **항상 객체의 중심선**이다.

1. **좌우 반전 (lr)** — 세로 중심선 기준 대칭: `(r,c) → (r, w−1−c)`
2. **상하 반전 (ud)** — 가로 중심선 기준 대칭: `(r,c) → (h−1−r, c)`

반전은 bbox를 바꾸지 않으므로(치수 h×w 불변) 정방형 제약도, 사이즈 parity 제약도 필요 없다.

## 4. 이동 — 없음 (제자리 반전)

모든 반전 문제는 **이동 없이 제자리**다. 객체는 자기 중심선을 축으로 반전되며 bbox 위치·치수 모두 불변. (이전 설계의 이동/기준선 축은 폐기.)

## 5. 조합 규모

객체분류(F-단일 3종 + F-다 3종 = 6) × 반전방향(2) = **12 조합 = 12 couple = 24 JSON 파일**. 사이즈는 축이 아니므로 곱하지 않는다.

## 6. 파일 네이밍

HARNESS.md §9 규칙: `flip000a`(2ex) / `flip000b`(3ex)부터 시작. 24 유닛이라 `flip000a`~`flip000x`까지 사용(단일 알파벳 범위 내). 조합↔파일 매핑은 `flip/MANIFEST.csv`(idx, file_2ex, file_3ex, object_class, flip_dir).

couple 순서: (mono, partial, full, sel_color, sel_size, sel_shape) × (lr, ud).

## 7. 생성 및 검증

생성 스크립트: 루트 `gen_flip.py` (rotate의 공통 로직 재사용, seed 고정 재현 가능).

구현 세부:

- **도형**: 지정 bbox extent를 채우는 4-연결 폴리오미노를 랜덤 생성(rotate와 공유).
- **반전**: 좌우/상하 중 하나를 bbox 로컬 좌표에 적용. bbox 불변이라 출력 객체는 입력과 같은 bbox 점유(제자리).
- **no-op 금지**: 반전 결과가 입력과 같으면(대칭 도형 등) 사이즈·모양 재추출. 단색 직선처럼 특정 사이즈가 항상 no-op이면 다른 사이즈로 재시도.
- **F-다**: 선택 근거별 불변식(색상 고정 / **크기 X 고정** / 모양 고정) 유지, 나머지 속성 랜덤화. 객체 간 8-이웃 간격 확보. (크기=대상 셀 수가 항상 X, distractor는 X≠, 더 클 수도 있음.)
- **couple 색상 차이(HARNESS §7)**: 2ex/3ex 색 집합이 다르도록 3ex 재생성.

**자동 검증 통과**: 24개 전수 — train 2/3, test 1, 그리드 4–10, 배경 0, 색 0–9, pair 내부 크기 고정, no-op 없음, 입출력 컬러 픽셀 수 동일, couple 색상 차이. 단일객체 42개 예시는 "입력 객체를 중심선 기준 좌우/상하 반전"과 출력이 정확히 일치함을 좌표 단위로 대조 확인.
