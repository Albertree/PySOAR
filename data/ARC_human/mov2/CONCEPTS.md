# mov2 폴더 — Concept 설계

`mov2`는 `move`와 **동일한 concept 구조·규칙**(30 couple = 60 파일)을 그대로 따르되, **객체 다양성**을 더한 버전이다. 파일 포맷/네이밍/색상 규칙은 루트 `HARNESS.md`를 따른다. 이동 의미론(선택 근거·기준점·목적지)은 `move/CONCEPTS.md`와 완전히 동일하므로 여기서는 요약 + 다양성 차이만 기술한다.

생성 스크립트: 루트 `gen_move2.py` (rotate 공통 로직 재사용, seed 고정 재현 가능). 파일 코드는 `mov2` → `mov2000a.json`(2ex) / `mov2000b.json`(3ex) …

## 1. concept 구조 (move와 동일, 30 couple)

| M-class | 객체 | 축 | couple 수 |
|---|---|---|---|
| **M1** | 단일 1×1 | 목적지(상대/절대/그리드우하단) | 3 |
| **M2** | 단일 다중셀 | 기준점(좌상단/우하단) × 목적지(상대/절대/그리드코너) | 6 |
| **M3** | 다객체 1×1 | 색 선택 × 목적지(상대/절대/그리드우하단) | 3 |
| **M4** | 다객체 다중셀 | 선택(색/크기/모양) × 기준점(2) × 목적지(3) | 18 |

- **목적지**: 상대=고정 오프셋 `(dr,dc)`(파일 내 일정), 절대=고정 좌표(파일 내 그리드 크기·좌표 고정 — HARNESS §3 예외), 코너=기준점 종류에 대응하는 그리드 모서리(1×1은 우하단).
- **기준점(M2/M4)**: bbox 좌상단 또는 우하단.
- **선택 근거(M3/M4)**: 색=대상 색 파일 내 고정 / 크기=대상 셀 수 X 파일 내 고정 / 모양=대상 도형 파일 내 고정. distractor는 각각 다른 색/크기/모양.
- 다객체 개수는 고정 아님(대상 1 + distractor 1~3). 조합↔파일 매핑은 `mov2/MANIFEST.csv`(idx, file_2ex, file_3ex, m_class, select, anchor, dest).

couple 순서: M1(3) → M2(6) → M3(3) → M4 색(6) → M4 크기(6) → M4 모양(6).

## 2. move 대비 추가된 객체 다양성

> **모든 객체는 단색(monochrome)이다.** (2026-07-25 확정 — 다색 객체는 사용하지 않는다.) 색상 구성 다양화는 제거했고, 나머지 다양성만 유지한다. 한 grid 안 모든 객체의 색은 서로 다르다(HARNESS move §5-1).

1. **모양 다양화** — 객체를 더 다양하고 불규칙한 4-연결 폴리오미노로 생성(bbox 최대 5×5, L·T·Z·지그재그·블롭 등). 기존 move의 작은 blob/직선 위주에서 확대.
2. **distractor 다양화** — 다객체(M3/M4)의 distractor 개수를 1~3으로, 모양·크기도 다양하게.
3. **색 팔레트 다양화** — 각 객체의 (단일) 색을 1–9에서 넓게 뽑아 한 문제에 등장하는 색 가짓수를 늘림.

## 3. 검증

**자동 검증 통과**: 60개 전수 —
- 구조: train 2/3, test 1, 그리드 4–10, 배경 0, 색 0–9, pair 내부 크기 고정, no-op 없음, 입출력 컬러 픽셀 수 동일, couple 색상 차이.
- 이동 의미론(전수): 정확히 한 객체만 이동(모양·색 보존), 나머지 객체 불변, 목적지 규칙(상대 오프셋 파일 내 일정 / 절대 좌표·그리드 크기 파일 내 고정 / 코너 정확), 선택 불변식(색 단색·일정, 크기 X 일정, 모양 일정) 모두 충족.

**다양성 실측**: 객체 다색 0%(전부 단색), grid당 객체 1~4개, 한 문제 색 가짓수 1~9 고르게 분포, bbox 크기 다양(최대 5×5).
