# rotate 폴더 — Concept 설계

`rotate` 폴더의 concept은 그리드 안 객체를 **회전**시키는 변환을 다룬다. 파일 포맷/네이밍/색상 규칙은 루트 `HARNESS.md`를 따르고, 객체 분류·색상 구성·선택 근거 축은 `flip/CONCEPTS.md`와 동일한 설계를 재사용한다.

> **개정 (2026-07-25)**: 회전 종류를 "CW 고정 × 횟수(1/2/3회)"로, 이동을 제거(전부 제자리 회전)하고, parity 축을 제거한 뒤 대상 객체 사이즈를 고정 틀에서 무작위로 뽑는 방식으로 바꿨다. 아래는 개정된 설계이며, 이전(방향×횟수/이동/기준점/parity) 설계는 폐기했다.

## 0. 전제 — 객체 크기 (사이즈 틀)

대상 객체의 bbox 크기는 아래 **고정 틀 10종**에서 무작위로 고른다. 모두 **가로·세로 parity가 동일**(홀×짝/짝×홀 금지)하다 — 제자리 90°/270° 회전은 bbox를 h×w↔w×h로 전치시키는데, `(h−w)`가 짝수여야 전치된 bbox의 중심이 정수 격자에 정렬되어 "제자리"가 성립하기 때문이다.


```
(1,3) (3,1) (2,2) (2,4) (4,2) (3,3) (3,5) (5,3) (4,4) (5,5)
```

> **파일 내 parity 통일:** 한 문제(파일) 안에서 회전 대상 객체의 bbox는 **모든 pair(train+test)가 같은 parity**여야 한다 — 전부 **홀×홀** 이거나 전부 **짝×짝**(혼합 금지). couple(2ex/3ex)은 같은 parity 공유, `MANIFEST.csv`의 `parity` 열에 기록. 홀×홀={(1,3)(3,1)(3,3)(3,5)(5,3)(5,5)}, 짝×짝={(2,2)(2,4)(4,2)(4,4)}. (sel_size X: 홀 5~8, 짝 3·5~8.)

## 1. 기본 분류 (객체 개수) — flip과 동일

| 분류 | 설명 |
|---|---|
| **R-단일** | 그리드에 회전 대상 객체가 하나뿐 |
| **R-다** | 그리드에 여러 객체가 존재, 그중 하나만 회전 대상 |

### 1-1. R-단일: 객체 색상 구성 (3종)

1. **단색** — 객체를 이루는 모든 셀이 같은 색
2. **부분 다색** — 색상 종류가 1보다 많고 객체 크기(셀 수)보다는 적음
3. **전체 다색** — 색상 종류 수 = 객체 크기(셀 수). (셀 수 ≤ 9 로 제한 — 색은 1–9만.)

### 1-2. R-다: 객체 선택 근거 (3종)

1. **색상** — 대상 객체의 색을 파일 전체에서 하나로 고정(나머지 속성은 예시마다 랜덤).
2. **크기** — 대상 객체는 셀 수가 **파일 내 고정 상수 X**인 객체(색·모양처럼 특정 값을 골라냄). distractor는 X가 아닌 크기(더 클 수도 있음). "가장 큰 객체"가 아니다.
3. **모양** — 대상 도형(cell 패턴)을 파일 내에서 하나로 고정해 모든 예시에 재사용(색은 예시마다 랜덤). distractor는 다른 모양.

> R-다의 각 객체는 **단색(monochrome)**. **색상 중복 금지**: 한 grid 안 모든 객체의 색은 서로 달라야 한다(선택 근거가 색상이 아니어도 동일 적용).

## 2. ~~가로/세로 parity 축~~ — 폐기

이전 설계의 parity 축은 제거했다. 대신 §0의 고정 사이즈 틀(모두 동일 parity)로 대체한다. **사이즈는 조합 축이 아니라** 문제마다 틀에서 무작위로 뽑는 자유 파라미터다.

## 3. 회전 종류 — CW 고정 × 횟수 3종

방향은 **시계방향(CW)** 으로 고정하고, **횟수**만 축으로 둔다.

1. **1회** = 90° CW
2. **2회** = 180°
3. **3회** = 270° CW (= 90° CCW)

## 4. 이동 — 없음 (제자리 회전)

모든 회전 문제는 **이동 없이 제자리 회전**이다. 객체는 자기 bbox 중심을 축으로 회전하며 중심 위치는 불변. (이전 설계의 이동/기준점 축은 폐기.)

- 90°/270°: bbox가 h×w → w×h로 전치되지만, §0의 동일-parity 제약 덕에 중심이 격자에 정렬된 채 제자리 유지.
- 180°: 치수(h,w) 불변.

## 5. 조합 규모

객체분류(R-단일 3종 + R-다 3종 = 6) × 회전횟수(3) = **18 조합 = 18 couple = 36 JSON 파일**. 사이즈는 축이 아니므로 곱하지 않는다.

## 6. 파일 네이밍

HARNESS.md §9 규칙: `rota000a`(2ex) / `rota000b`(3ex)부터 시작, `z` 이후 `aa, ab, ...`로 확장. 36 유닛이라 마지막은 `rota000aj`. 조합↔파일 매핑은 `rotate/MANIFEST.csv`(idx, file_2ex, file_3ex, object_class, rotate_count, rotate_deg)에 있다.

couple 순서: (mono, partial, full, sel_color, sel_size, sel_shape) × (1회, 2회, 3회).

## 7. 생성 및 검증

생성 스크립트: 루트 `gen_rotate.py` (seed 고정, 재현 가능).

구현 세부:

- **도형**: 지정 bbox extent(h×w의 4변을 모두 접함)를 채우는 4-연결 폴리오미노를 랜덤 생성.
- **회전**: 90° CW를 k회 적용(좌표 변환), 전치된 bbox를 원 bbox 중심에 맞춰 재배치(제자리).
- **no-op 금지**: 회전 결과가 입력과 같으면(대칭 도형 등) 사이즈·모양을 재추출. 단색+180°처럼 특정 사이즈가 항상 no-op이면 다른 사이즈로 재시도.
- **R-다**: 선택 근거별 불변식(색상 고정 / **크기 X 고정** / 모양 고정)을 유지하고 나머지 속성은 예시마다 랜덤화. 객체 간 8-이웃 간격을 둬 서로 붙지 않게 배치. (크기=대상 셀 수가 항상 X, distractor는 X≠, 더 클 수도 있음.)
- **couple 색상 차이(HARNESS §7)**: 2ex/3ex의 색 집합이 다르도록 3ex를 재생성.

**자동 검증 통과**: 36개 전수 — train 2/3, test 1, 그리드 4–10, 배경 0, 색 0–9, pair 내부 크기 고정, no-op 없음, 입출력 컬러 픽셀 수 동일, couple 색상 차이. 단일객체 63개 예시는 "입력 객체를 제자리 k회 CW 회전"과 출력이 정확히 일치함을 좌표 단위로 대조 확인.
